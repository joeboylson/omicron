## Findings

Six critics, one or two use cases each: the household Project (Claire) and a new person (Sam); working tasks one at a time and the morning review; the overnight run and a team's question; Projects, people and machines; keyboard only; the Dev view. Merged, checked against the code, and filed as tasks labelled `ux` (most important first):

- #142 (high) On a phone, only one board column shows, with no way to see or jump to the others
- #143 (high) On a phone, the board's header takes half the screen before the first task
- #144 (high) The People and Machines tables are unreadable on a phone
- #145 (high) Deleting a person while filtered to a Project deletes them from everything
- #146 (high) The task sheet hides which field has keyboard focus
- #147 (high) Moving a task by keyboard reads database ids to a screen reader
- #148 (high) After deleting a task, Undo can't be reached by keyboard
- #149 (high) The Dev view on a phone hides the sessions list and This computer
- #150 (high) The phone terminal has no Esc, Ctrl, Tab or arrow keys
- #151 (high) The gate's words contradict what the owner can do on the serving computer
- #152 (high) A run doesn't show the gate of the computer doing it
- #153 (high) No way to see that a team is waiting on you, or that your answer was held or delivered
- #154 (high) Dispatch's panel says three contradictory things
- #155 (high) Comment images can't really be looked at on a phone
- #156 (high) The sign-in error is in programmer words
- #157 (medium) A trash icon on every Project row, the row's only action
- #158 (medium) No hint how to add someone who isn't in Omicron yet
- #159 (medium) Project settings' Members shows one name in a closed picker
- #160 (medium) Household Projects' settings are full of Claude-only parts
- #161 (medium) A machine's status can't tell new from dead, and Switch off isn't explained
- #162 (medium) Settings is hard to find and Machines keys are explained nowhere before making one
- #163 (medium) A search with no matches shows empty columns, not a message
- #164 (medium) Filters and due dates are hard to read
- #165 (medium) A task's labels all look chosen
- #166 (medium) Topics and Given to disagree about whose task it is
- #167 (medium) Adding a task can't set who or when, and gives little feedback on a phone
- #168 (medium) The page for a Project you can't see is a bare line
- #169 (medium) The run's controls and sheet don't say what they'll do
- #170 (medium) A session's sheet starts with a temp path and never says what it's doing
- #171 (medium) Giving a session's tasks away is ambiguous
- #172 (medium) An ended session's task reads differently on the card and in the sheet
- #173 (medium) A session's report is signed by the computer, not the session
- #174 (medium) Keyboard: no way to move a task except drag, and the board is Tab-only
- #175 (medium) Keyboard: menu and command highlights are almost invisible
- #176 (medium) Keyboard: adding a task loses your place, and shortcuts are hard to learn
- #177 (medium) The Dev view's task list and session list say too little
- #178 (medium) Folder rows in the Dev view: cut-off paths and an unlabelled +
- #179 (medium) This computer: checks without fixes, cut-off text, an unclear loop form
- #180 (low) Dev view polish: terminal look, End, This computer's place, run bar
- #181 (low) One orange for Needs review, Review, waiting and ended
- #182 (low) Column and task menus are thin, and 'Organize' is an odd word
- #183 (low) ⌘K: the page's own commands come last, the theme isn't ticked, Appearance is cut off
- #184 (low) Small programmer-ish details for non-technical people
- #185 (low) Checklist and comments sit far down a task on a phone

Dropped: "phone keys typed twice" (the desktop and phone passes typed into the same session); "can't clear Needs review" (the sheet has a Reviewed button when it's marked); "the run never names its task" (no daemon ran in the pictures; normally the bar says "on #n"); "Mark done is hidden in ⋯" (Joe chose that, #60); "Given to has no Claude sessions" (House has none; Lumen's picker lists them).

Not yet photographed (add to dev/seed/shots.js): a team's question and jobs; an answer held by a closed gate; the gate open with a closing time; a run working on a task; the sign-in error on a phone.
