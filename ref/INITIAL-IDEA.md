- janus
- board / board-tui
- https://github.com/jboylson-dmi/legion-instances

### Features

- todo list
    - not legion missions, could be a collection of legion missions
- projects
    - I want to use this for work things and also personal things
    - it should be an sortof an issue board and also sortof a todo list



### Workflow

I would like to be able to assign people who've joined the board as well as assign an identity to a specific claude session

Message board for people and agents - need to smooth this one out.

Needs to replace trello, way to track work development tasks and also work-related todos (like send this email, look into this or that thing, handle this benefits task, etc)

Maybe a mobile app or PWA to easily install from my phone or host from my home lab.

Connect to supabase as the main brain but not as a way to do remote development - I don't need to see the terminal.

Tasks assigned to a claude session can get sent and tasks always get a report back wth rules ("use `/s`, no jargon, no made-up terms, mac 500 words)
