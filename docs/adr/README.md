# Decision records

One file per decision made from now on, numbered: `0001-<slug>.md`. Each says
what was decided, why, and what was ruled out, in plain words.

Decisions made before 14 Nov 2026 are in `ref/BRAINSTORM.md`, by topic.
Architecture reviews (`/improve-codebase-architecture`) read both, so a
candidate that a decision already ruled out isn't suggested again.
