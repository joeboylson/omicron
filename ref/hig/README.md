# Apple's Human Interface Guidelines, for Omicron

Plain-language summaries of the HIG pages that bear on Omicron's web page (read from Apple's pages on 14 Nov 2026, #194). Rules are numbered so a task can cite "HIG buttons #4". Each file names its source page and says how the rules apply to a page in a browser on iPhone and Mac. Used by `/hig-review`.

Omicron's own rules come first where they're stricter: no explanatory subtitles or help text, no jargon, made-up terms or developer language; the page explains itself to someone with no technical skills.

Navigation bars are in toolbars.md (Apple merged them); badges have no page of their own (tab-bars.md #8).
